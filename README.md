# Mizan Law Firm | شركة ميزان للمحاماة

Premier bilingual legal counsel and digital forensics consultancy based in Erbil, Kurdistan Region, Iraq.

**Official Website**: [https://the-mizan.net](https://the-mizan.net)

## Core Practice Areas
- **Cybercrime Defense & Anti-Extortion**: Emergency containment of ransomware, cyberfraud, blackmail, and unauthorized access.
- **Digital Forensics & Chain-of-Custody**: Hardware bit-stream imaging, volatile memory analysis, chat recovery, and court-ready expert witness testimony.
- **General Litigation & Corporate Law**: High-stakes commercial arbitration, criminal defense, contract disputes, and family wealth succession.
- **Intellectual Property & Digital Rights**: Trademark portfolio protection, software copyright enforcement, and swift anti-piracy takedowns.

## Tech Stack
- **Framework**: Next.js 15 (App Router, Static Export)
- **Runtime**: React 19
- **Deployment**: GitHub Pages (`https://the-mizan.net`)

## Local Development
```bash
npm install
npm run dev
```

## Production Build & Static Export
```bash
npm run build
```
Static production assets are exported into the `out/` directory.
